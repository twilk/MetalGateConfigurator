## Aktualizacje Dokumentacji

Dokumentacja technologii jest pobierana z oficjalnych źródeł i może być aktualizowana przez:

```bash
# Aktualizacja dokumentacji Three.js
curl -o docs/threejs-docs.md https://raw.githubusercontent.com/mrdoob/three.js/dev/README.md

# Aktualizacja dokumentacji jsPDF
curl -o docs/jspdf-docs.md https://raw.githubusercontent.com/parallax/jsPDF/master/README.md

# Aktualizacja dokumentacji MDN
curl -o docs/html5-docs.md https://raw.githubusercontent.com/mdn/content/main/files/en-us/web/html/index.md
curl -o docs/css3-docs.md https://raw.githubusercontent.com/mdn/content/main/files/en-us/web/css/index.md
curl -o docs/javascript-docs.md https://raw.githubusercontent.com/mdn/content/main/files/en-us/web/javascript/index.md
```
